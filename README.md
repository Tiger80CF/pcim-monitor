## Overview

The Private Credit Intelligence Monitor (PCIM) is a real-time intelligence dashboard for senior insurance executives (CFO, CRO, CAO) overseeing general account private credit exposure at US life insurers.

## Features

- **26 embedded intelligence cards** spanning direct lending, distressed debt, CLO tranches, regulatory developments, and macroeconomic indicators
- **AI Synthesis Engine** generating real-time risk posture narratives from card data
- **KPI Dashboard** — HY OAS, IG spreads, C&I lending tightening, direct lending spreads with trend sparklines
- **Multi-dimensional filtering** — Signal type, Domain, Agent Source, Scenarios, Trending Tags
- **Content Submission & Evaluation** — upload and heuristically score new sources for relevance and credibility
- **Content Queue** — review/approve workflow for submitted content before promotion to active cards
- **Regulatory Feed** — NAIC, IAIS, and federal regulatory pipeline tracking
- **Executive PDF Report** — print-optimized intelligence report for CFO/CRO/CAO distribution
- **Automated Weekly Content Search** — scheduled scan for high-credibility private credit content

## Files

| File | Description |
